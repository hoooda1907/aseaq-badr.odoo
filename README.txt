2) Actions -> انتظر علامة صح ✅ -> Artifacts -> aswaq-badr-windows
   AswaqBadr-Setup.exe (تنصيب)  |  AswaqBadr-Portable.exe (بدون تنصيب)

الدخول الأول: أسواق بدر / 2027 (مدير النظام)
ثم: استيراد وتحديث البيانات -> المنتجات / الموردين / الموظفين

مجلد "أسواق بدر" على سطح المكتب:
  Sales\Sales-التاريخ.xlsx      مبيعات اليوم تلقائيًا
  Sessions\Session-رقم.xlsx     تقرير إغلاق الجلسة
  Reports\...                   تقارير الحسابات
  Backup\backup.json            نسخة احتياطية (بدون المنتجات)
بيانات البرنامج نفسها محفوظة في: %APPDATA%\aswaq-badr\db
